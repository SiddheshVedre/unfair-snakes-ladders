UNFAIR SNAKES & LADDERS — WEB PROJECT

Run locally in VS Code:
1. Extract this project folder.
2. Open the folder in Visual Studio Code.
3. Install the "Live Server" extension by Ritwick Dey.
4. Right-click index.html and choose "Open with Live Server".

Publish online with GitHub Pages:
1. Create a GitHub account and a new public repository.
2. Upload index.html (or upload the contents of this folder).
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. Wait for GitHub Pages to publish. Open the URL shown in Settings > Pages.

The game is a static HTML/CSS/JavaScript project. It does not require Node.js,
npm, a database, or a backend server. Keep the file named index.html for hosting.
